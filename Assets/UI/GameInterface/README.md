# Игровой интерфейс

Escape или кнопка «Пауза» открывает меню поверх размытого игрового кадра.
«Продолжить» возвращает в игру; «В главное меню» загружает MainMenu.
Escape в настройках возвращает к паузе, повторное нажатие продолжает игру.
Во время паузы мир, расход ресурсов, телекинез и еда остановлены.

Ресурсы игрока:
- Сытость постепенно убывает: 0.08 единицы в секунду.
- Удержание предмета телекинезом тратит 8 магии в секунду.
- Каждая потраченная единица магии дополнительно расходует 0.35 сытости.
- При нехватке магии предмет отпускается.
- Магия самостоятельно не восстанавливается.
- Паёк восстанавливает 35 сытости и 45 магии. Подойдите и нажмите E.
- При полностью заполненных шкалах паёк не тратится.
- Три образца пайков сохранены выключенными для ручного размещения.

Баланс меняется на компоненте PlayerEnergy у Player и FoodPickup у пайков.
Нулевая сытость пока не наносит урон: система здоровья не добавлялась.

Файлы:
PlayerEnergy.cs — запасы и расход ресурсов.
FoodPickup.cs — съедобный предмет рядом с игроком.
GameInterface.cs — шкалы, пауза, настройки и переход в меню.
PauseBlur.shader — размытие. Один снимок при открытии паузы,
поэтому размытие не пересчитывается каждый кадр.
TelekinesisObject.cs — существующая механика, дополнена расходом ресурсов
и проверкой паузы; остальные действия сохранены.

Сцена Laboratory содержит GameCanvas. Внешний вид редактируется в сцене.
