# Wall Palette

Палитра **Laboratory Walls**: одна клетка — один спрайт **32×32**, PPU 32, pivot (16,16), Point, без mipmaps и сжатия.

Синие верха и автоматическая кисть сохранены. Молочные лицевые стены и столбы разделены на **верхнюю и нижнюю части**. Для целого участка или столба выделяйте **две клетки по вертикали**. Между отдельными образцами оставлено место; ниже лицевых частей собран пример непрерывной стены с двумя торцами.

`WallFaces.png` содержит восемь частей 32×32. Прозрачная часть верхней клетки оставляет место для синего верха; реальная высота молочной стены сохранена. В игровом Tilemap верхняя часть остаётся на прежней клетке, нижняя находится на одну клетку ниже.

`Pillars.png` содержит восемь частей 32×32. Их пары точно восстанавливают четыре исходных столба. `WholePillars.png` хранит цельные изображения только для префабов с коллайдерами; в палитре используются отдельные клетки 32×32.

Все 102 существующих лицевых участка перенесены на пары частей. Дополнены 13 недостающих углов; всего на карте 115 пар. Планировка и исходные пользовательские изменения карты сохранены. Лицевые поверхности находятся под синими верхами, поэтому на углах не накрывают боковую стену.
