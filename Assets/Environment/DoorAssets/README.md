# Door Assets

Двери используются как цельные префабы. Фрагменты DoorTiles и палитра Door States удалены.

`Doors.png`: шесть горизонтальных кадров 160×64. `VerticalDoors.png`: шесть отдельных видов сверху 32×128 для боковых проходов. Оба листа используют 32 PPU, центральный pivot, Point и Full Rect. Все кадры одного листа имеют одинаковый размер. Делить один кадр двери на клетки не нужно.

Состояния: Closed Red, Closed Green, Opening Start, Opening Half, Opening End, Open Green. Красный вариант оставлен для будущих запертых дверей. Работающие двери используют пять зелёных кадров.

На карте 11 рабочих дверей: 8 горизонтальных и 3 боковых. Префабы `Horizontal Door` и `Vertical Door` закрыты по умолчанию. `LabDoor` открывает дверь рядом с игроком и закрывает после его ухода. Коллайдер выключается только после полного открытия. Во время паузы дверь не двигается. Расстояния и скорость открытия редактируются в Inspector.

Проём занимает 3 клетки. Для горизонтального проёма с началом (x,y) центр префаба — (x+1.5,y). Для вертикального — (x+0.5,y+1.5). Поворот обоих типов 0°, Scale (1,1,1). Боковая дверь использует собственный вид сверху, а не повёрнутую фронтальную картинку.

`Horizontal Join` и `Vertical Join` ставятся на два соседних с проёмом торца стены. Контактные пиксели дверной рамки совпадают с профилем синей стены. Планировка помещений сохранена.

Проверки: `Tools/DoorReview.cs` проверяет кадры и стыки; `Tools/DoorRuntime.cs` проверяет в Play mode открытие, закрытие и проход персонажа через каждую дверь с обеих сторон. Отчёты лежат в `TestResults`.
