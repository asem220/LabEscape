# Door Assets

Дверь для горизонтального проёма шириной 3 клетки. Один тайл — 32×32 пикселя, PPU 32.

`Doors.png` — шесть кадров для будущей анимации. Все кадры имеют одинаковые размеры 160×64 и центральный pivot. Порядок: Closed Red, Closed Green, Opening Start, Opening Half, Opening End, Open Green.

`DoorTiles.png` — те же изображения, разбитые на части 32×32. В палитре **Door States** каждый вариант собран блоком **5×2 клетки**. Выделяйте весь блок для целой двери.

Почему 5 клеток: центральные 3 приходятся на проём; внешние клетки дают место рамке, которая стыкуется с концами синих стен. Сама видимая рамка имеет ширину 104 пикселя: проём 96 и по 4 пикселя на косяки. У синих стен торцы также отступают на 4 пикселя от края клетки.

Для проёма, начинающегося в клетке (x,y), ставьте нижний левый угол выбранного блока в (x-1,y-1). Префаб целой двери ставится центром в (x+1.5,y). Префабы Closed Red и Closed Green содержат препятствие; Open Green имеет прозрачный свободный проход.

На карте двери пока не расставлены. Анимация и переключение состояния кодом не подключены: это заготовленные совместимые кадры. Рамка не меняет положение между кадрами; створки раздвигаются симметрично. Переход красного индикатора в зелёный не изменяет геометрию.

Визуальная основа создана встроенным image_gen по референсу пользователя, затем выровнена на пиксельной сетке. Все кадры собраны из одной исходной рамки и одинаковых створок, чтобы исключить дрожание при будущей анимации.
