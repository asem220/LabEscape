# Больничный тайлсет

Стены и пол — разные PNG. Карта собирается из настоящих Tilemap-клеток,
а не из растянутой картинки комнаты.

HospitalWalls.png — 47 модульных вариантов, каждый ровно 32 x 32 пикселя.
Атлас: 256 x 192, восемь столбцов. Последняя клетка пустая.
HospitalFloor.png — отдельный тайл пола 32 x 32, без стен.

Импорт: PPU 32, Point, без сжатия и mipmaps. Нарезка сохранена в Sprite Editor.
Palettes/Hospital.prefab — готовая Tile Palette:
- верхняя левая кисть HospitalWall автоматически выбирает края и углы;
- рядом находится пол;
- ниже доступны все 47 отдельных тайлов для ручной работы.

Рисовать стены нужно на FacilityLayout/Walls, пол — на FacilityLayout/Floor.
Не размещайте стены на слое пола: у пола намеренно нет коллайдера.
HospitalWallTile.cs задаёт коллизию Grid для каждой занятой клетки стены.
TilemapCollider2D и CompositeCollider2D обновляют столкновения после рисования.
Старый декоративный WallFaces выключен: его клетки перенесены в настоящие стены.

Для пиксельной правки откройте нужный PNG в Aseprite, включите сетку 32 x 32,
редактируйте конкретные клетки и сохраните PNG под тем же именем.
Не меняйте размеры атласа и расположение тайлов — тогда существующая нарезка
и ссылки карты сохранятся. Unity подхватит изменённые пиксели автоматически.
Кисть выбирает варианты по соседям; повторения одной клетки используют один спрайт.

Рабочие PNG сделаны попиксельно в ограниченной палитре.
Из референсного видео применён метод: базовый профиль, симметричные переходы,
внешние и внутренние углы, проверка повторением. Ассеты автора не использованы.
Сгенерированные ранее концепты не подключены к проекту.

Проверка:
- 49 152 сравнений пикселей на стыках — без расхождений;
- все 1 276 видимых клеток стен имеют коллизию;
- все 10 комнат доступны с учётом мебели и капсулы игрока;
- проверены движение в стену и проход через дверь в Play Mode.
