# LabEscape

Пиксельная 2D-игра про побег из лаборатории. Проект для **Unity 6000.6.6f1**, URP 2D.

Открой папку проекта через Unity Hub. Главная сцена — `Assets/Scenes/MainMenu.unity`, игровая — `Assets/Scenes/Laboratory.unity`. В сборку входят эти две сцены; прежние сцены сохранены в папке Scenes.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Съесть еду рядом | E |
| Поднять или отпустить предмет под курсором | E |
| Зарядить и бросить предмет | Удерживать и отпустить левую кнопку мыши |
| Пауза, назад | Escape |

Магия расходуется на телекинез и восстанавливается едой. При использовании магии дополнительно расходуется сытость. Пауза останавливает время и размывает фон. Выход через нижний шлюз возвращает в главное меню.

## Стены

Ассеты находятся в `Assets/Environment/WallAssets`. Палитра — `Laboratory Walls`, автоматическая кисть — `WallAutoBrush47.asset`.

Верх стены, лицевая поверхность и пол редактируются отдельно. Верхи нарезаны по 32×32 пикселя, лицевые поверхности — по 32×48, столбы — по 32×64. Настройки: 32 PPU, Point, без mipmaps и сжатия. Соседние тайлы выбираются автоматически, включая внутренние углы и ответвления.

Столбы с коллайдерами лежат в папке `Prefabs`. Мебель, образцы еды и предмет для телекинеза сохранены выключенными: их можно включить или разместить копии при наполнении уровня. Расположение комнат сохранено. Охрана и туман войны пока не реализованы.

## Проверки

Результаты находятся в `TestResults`, сценарии — в `Tools`. Проверены сцены и ссылки, меню и настройки, пауза, питание, магия, ввод, телекинез, столкновения, маршруты, стыки тайлов и Windows-сборка. Игровые сценарии повторены несколько раз.

Сценарии запускаются через Unity CLI при открытом проекте. Например, из корня проекта:

```powershell
unity command script run --file Tools/SceneReview.cs --entry SceneReview.Main --caller plugin --skill unity-cli --format json
unity command script run --file Tools/WallReview.cs --entry WallReview.Main --caller plugin --skill sprite-editor --format json
```

Проверки ResourcesReview, PhysicsReview, InputReview и GameReview требуют Play mode. Проверки SceneReview, RouteReview, WallReview и BuildReview запускаются в Edit mode, с открытой сохранённой сценой Laboratory. Сценарии ввода используют временные тестовые устройства и восстанавливают настройки после выполнения. BuildReview сохраняет игру в папку Build, которая исключена из Git.
