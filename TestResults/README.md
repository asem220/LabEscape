# Test Results

Проверка проекта выполнена 28 октября 2026 года в Unity 6000.6.6f1.

## Исправления

- Стены перекрывали голову персонажа перед ними. Верхи стен и персонаж теперь сортируются по Y на одном порядке отрисовки.
- Новая или включённая после старта еда отсутствовала в сохранённом списке интерфейса. Активная еда теперь регистрируется при включении и удаляется из списка при выключении.
- Отключение одного предмета отключало общее действие ввода остальных предметов. Каждый предмет теперь владеет своими действиями ввода.
- Отрицательные параметры и пустая еда могли изменять ресурсы или расходовать паёк без восстановления. Неподходящие значения отклоняются.
- После очистки декора отсутствовал триггер выхода. Восстановлен невидимый триггер шлюза без установки двери или мебели.
- Главное меню, настройки сборки и имя игровой сцены согласованы: Laboratory.

## Повторные проверки

В папках First, Second и Third сохранены отдельные результаты каждого прогона.

| Группа | Проверки | Результат |
|---|---|---|
| Ресурсы | 9 проверок × 3 прогона | Все прошли |
| Ввод | Меню, WASD, еда по E, подбор и бросок, пауза — 3 прогона | Все прошли |
| Физика | Вертикальная стена, горизонтальная стена, свободный проём — 3 прогона | Все прошли |
| Переходы | 3 входа в игру, 9 циклов паузы, возвраты в меню, выход через шлюз | Все прошли |
| Сцены | 5 сцен, ссылки компонентов и обработчики кнопок | Потерянных ссылок и скриптов нет |
| Тайлы | 512 сочетаний соседей, 8192 сравнения верхов и 192 сравнения лицевых частей | Несовпадений нет |

Проверены остановка ресурсов и движения на паузе, восстановление магии только едой, нормальная скорость по диагонали, отсутствие дублирующего EventSystem после переходов и освобождение текстуры размытия после паузы. Перекрытие персонажа стеной дополнительно проверено визуально в игре.

Точный результат сборки находится в Build.json. Это проверка реализованных систем прототипа; охрана, туман войны и будущие игровые механики в неё не входят.

## Palette repair

29 октября 2026: палитры приведены к частям 32x32. Восстановление столбов: 8192 пикселя совпали; проверка стыков лицевых частей: 256 сравнений без ошибок; проверка неподвижной рамки дверей: 6528 сравнений без ошибок. На карте 115 пар лицевых тайлов, дополнены 13 углов. Открытый кадр двери прозрачен. Маршруты ко всем восьми контрольным точкам доступны. Подробности — Palette.json. Это проверка ассетов и сцены; отчёт Build.json относится к предыдущей Windows-сборке.
